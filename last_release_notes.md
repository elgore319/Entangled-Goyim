## Entangled Goyim v1.0.0

First release of Entangled Goyim, a new project based on Noita Entangled Worlds v1.6.6.

The proxy now updates itself and downloads the mod from this repository's releases.

### Installation

Download `noita_proxy-win.zip`, `noita_proxy-linux.zip` or `noita_proxy-macos.zip` below, unpack it and launch the proxy. The proxy can download and install the mod automatically.
