## Entangled Goyim v1.0.1

### Changes
- Proxy downloads are now named `goyim_proxy-*.zip`.
- The mod shows as **Slugma's Entangled Goyim** in Noita's mod list.

### Installation

Download `goyim_proxy-win.zip`, `goyim_proxy-linux.zip`, `goyim_proxy-macos-arm64.zip` (Apple Silicon) or `goyim_proxy-macos-intel.zip` (Intel) below, unpack it and launch the proxy. The proxy can download and install the mod automatically. If you're already on v1.0.0, the proxy's update button will update you.

The `noita_proxy-*.zip` files are copies kept so v1.0.0 proxies can update themselves; new players should use the `goyim_proxy-*.zip` files.
